# 1.1.1 视觉弹窗验证

2026-09-14，Android 16 / API 36 Google APIs x86_64 模拟器。

## 改动

- 应用前台继续使用 Compose AlertDialog。
- 应用后台、视觉模式且已授权悬浮窗时，精确闹钟触发独立 PopupService，使用 TYPE_APPLICATION_OVERLAY 显示结束弹窗。
- PopupService 使用声明用途的 specialUse 前台服务；弹窗存在期间保留通知，确认后释放窗口及服务。它与最长一分钟的响铃服务独立，声音结束不会关闭未确认的视觉提醒。
- 返回主界面时移除悬浮窗，由原应用内弹窗接管。重置、新计时或确认提醒会清理旧窗口。
- 没有悬浮窗权限或系统拒绝窗口时保留原有结束通知；主界面明确说明授权入口。系统锁屏及拒绝悬浮窗的安全页面仍可能隐藏窗口，不绕过系统限制。

## 测试

- 新增 6 项 Android 集成测试全部通过，用时 47.785 秒：后台纯视觉弹窗保持到确认、仅响铃不弹窗、无权限回退通知、前台／后台切换、组合提醒关闭时停止响铃、服务启动瞬间重置不遗留窗口。
- 既有 JVM 10 项计时和更新策略测试通过，Release 构建和 Android Lint 通过，无错误。
- 发布使用 versionCode=3、versionName=1.1.1，沿用原 RSA 发行签名。
- 实际在桌面后台运行 45 秒纯视觉倒计时，截图确认出现独立居中弹窗；点击“知道了”后 dismissed=true，PopupService 销毁。该检查未通过启动计时器 Activity 代替后台弹窗。
