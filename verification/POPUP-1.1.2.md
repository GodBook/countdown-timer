# 1.1.2 后台弹窗修复验证

日期：2026-09-14。环境：Android 16 / API 36 Google APIs x86_64 模拟器，JDK 17，targetSdk 36。

## 修复依据

1.1.1 仅在结束回调判断应用处于后台时启动弹窗，结束与退出应用交错时会漏掉提醒；同时需要到时才启动后台服务。本版在视觉倒计时开始时提前启动前台提醒服务，计时和暂停期间复用原倒计时通知。服务持续观察计时状态及 Activity 的恢复／暂停状态，未确认的结束提醒在退出应用后补显示。

窗口使用关联默认显示屏的 WindowContext。服务重建读取持久状态；精确闹钟继续负责到时触发，服务内检查提供进程存活期间的辅助触发。重置、确认及新计时按状态清理旧窗口。窗口和服务启动失败保留诊断记录并提示用户。

## 正式 APK 实测

- 安装已发布的 1.1.1，授予通知和悬浮窗权限，然后以 `adb install -r` 覆盖安装固定发行签名的 1.1.2：成功，授权保留。
- 在实际界面点击“5 秒后台弹窗测试（返回桌面）”：桌面出现独立居中“时间到”弹窗；点击“知道了”后关闭。
- 从实际界面开始 30 秒视觉倒计时，切换到 Google 时钟应用。确认 PopupService 已在计时结束前以前台服务运行，通知 ID 为 10。
- 上述倒计时途中，使用模拟器 root 执行 `kill -9` 终止应用进程（不是系统强制停止）。进程从 PID 9208 恢复为 9750，到时在 Google 时钟应用上方出现居中弹窗。窗口检查为 `isVisible=true`、`HAS_DRAWN`。
- 系统设置的通知页面测试：到时显示横幅通知，没有可见的居中窗口。因此不能承诺所有系统页面均允许显示悬浮窗。
