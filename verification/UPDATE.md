# 1.1.0 应用内更新验证

日期：2026-09-14；Android 16 / API 36 模拟器，JDK 17。

- JVM 测试共 10 项通过：原有计时状态 7 项、更新策略 3 项。更新策略覆盖版本前进、同版本／旧版本不更新、系统版本要求、非官方 URL、错误摘要和超大文件。
- Android 更新集成测试 3 项通过：同签名高版本 APK 被接受；不同签名高版本 APK 被拒绝；大小或 SHA-256 错误被拒绝；清单解析及未知 schema 拒绝。
- 校验测试用高版本 APK 仅保存在本地 dist 中，没有发布至 GitHub，也不纳入源码压缩包。
- Release 构建和 Lint 通过，无错误；使用与 1.0.0 相同发行签名。
- 更新检查与下载使用 HTTPS，只接受指定 GitHub 仓库的 Release APK。下载完成后再次核对包名、版本和签名，安装前重新校验本地文件。
- 更新服务端使用 GitHub Release 的 `update.json`，更新清单及附件先放入草稿 Release，完整上传后再公开。

实际用户安装仍需 Android 确认，不提供静默安装。网络无法访问 GitHub 时会显示手动检查失败提示，计时本身不受影响。
